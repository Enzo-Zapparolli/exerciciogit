# Calculadora básica — exercício de Git e Python

**Laboratório de aprendizado.** Duas funções simples para praticar código Python e versionamento.

[Portfólio](https://github.com/Enzo-Zapparolli) · [Código](calculadora.py)

## Funcionalidades

- `soma(a, b)`: retorna a soma.
- `subtracao(a, b)`: retorna a diferença.

## Experimentar

Na pasta do repositório:

```bash
python -c "from calculadora import soma, subtracao; print(soma(2, 3)); print(subtracao(5, 2))"
```

Saída esperada: `5` e `3` em linhas separadas. O arquivo define funções; executá-lo sozinho não abre uma interface interativa.
